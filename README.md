# Fraud Assignment Portfolio

Portfolio page for Prashant Dubey's fraud analytics assignment, built as a static GitHub Pages site.

## Projects

- Fraud Detection using BiGAN and AnoGAN
- GNN Classification
- Spectral Clustering
- Synthetic Data Generation via VAE

## View Locally

Open `index.html` in a browser.

## Publish With GitHub Pages

In the GitHub repository, go to **Settings > Pages**, then select:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/root`

The site will publish from this repository after GitHub finishes the Pages deployment.

## Overview

This repository brings together four fraud analytics experiments using modern machine learning techniques. The work explores how anomaly detection, graph learning, clustering, and generative modeling can help identify suspicious financial patterns from complex data.

The goal is not just to keep notebooks online, but to present them as a readable project portfolio for recruiters, reviewers, and collaborators.

---

## Featured Projects

| Project | Method | What it Shows |
| --- | --- | --- |
| [Fraud Detection using BiGAN and AnoGAN](./Fraud%20Detection%20using%20BiGAN%20and%20AnoGAN.ipynb) | Adversarial anomaly detection | Detecting unusual transaction behavior with deep generative models |
| [GNN Classification](./GNN_Classification.ipynb) | Graph Neural Networks | Learning from relationship-driven fraud signals |
| [Spectral Clustering](./Spectral%20Clustering.ipynb) | Unsupervised learning | Finding hidden groups and suspicious clusters |
| [Synthetic Data Generation via VAE](./Synthetic%20Data%20Generation%20via%20VAE.ipynb) | Variational Autoencoder | Creating synthetic samples for privacy-aware experimentation |
